# Starbie Firmware

Arduino source code for the Starbie virtual pet powered by the Seeed Studio XIAO ESP32-C3.

## Setup & Flashing
1. Open [`Starbie/Starbie.ino`](Starbie/Starbie.ino) in the Arduino IDE.
2. Make sure the ESP32 board package is installed (**Tools > Board > esp32 > XIAO_ESP32C3**).
3. Install the required libraries via the Arduino Library Manager:
   - `Adafruit GFX Library`
   - `Adafruit SSD1306`
   - `Adafruit MPU6050`
   - `DHT sensor library`
4. Plug in your board via USB-C and hit **Upload**.
